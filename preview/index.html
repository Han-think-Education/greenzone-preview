    새 장소를 만들거나 제안 후보를 실제 배출장소로 확정하지 않습니다.

안내 웹

03 / SERVER

조회와 정보 수정

FastAPI·SQLite. 담당자 세션, 수정 충돌 확인, 변경 기록.
