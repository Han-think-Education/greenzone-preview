질문하기

Ollama 확인 중
일반쓰레기, 재활용품, 폐건전지, 대형폐기물에 대해 질문하세요. Ollama 모델이 준비되면 실제 생성 결과를 보여줍니다.

LangGraph 실행 구성

01 classify_intent품목·의도 분류
↓
02 validate_input알 수 없는 품목 차단
↓
03 query_rules확인된 DB 데이터 조회
↓
04 build_response사용자용 안내 생성
↓
05 validate_output확인되지 않은 장소 안내 금지

Ollama 연동은 구현되었습니다. 오른쪽 노드 그래프는 LangGraph 도입 예정 설계도이며 현재는 FastAPI 분기 함수로 동작합니다.
