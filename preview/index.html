    저장된 안내 사용
    안녕하세요! 해우리 배출도우미예요. 버릴 물건과 궁금한 점을 알려주세요. 안마의자·책상·소파 등은 공식 품목표에서 규격별 수수료와 신고 방법을 찾아드려요. 물건이 모호하면 품목·규격을 되물어요. 전국 공통 분리 방법과 두 구의 확보된 운영 규칙도 찾아드려요. 특정 수거함 좌표는 아직 준비 중이에요. 모르는 장소나 시간은 지어내지 않아요.

    답변이 만들어지는 방식

    1. 품목 확인 → 공식 품목표 조회

      표준 품목명과 다른 표현으로 규격별 수수료를 찾습니다. 안마의자는 일반 의자와 구분하고 규격을 임의로 선택하지 않습니다.

    2. 지역·품목·시행기간 확인

      원문 확인 상태와 적용 대상을 먼저 확인합니다. 다른 지역이나 확인되지 않은 동별 규칙은 섞지 않습니다.

    3. 관련 문서와 원문 찾기

      선택한 BGE-M3 임베딩 또는 키워드로 검색합니다. 안내 내용과 공식 원문 링크·확인일을 함께 보여줍니다.

    4. 미확인은 그대로 안내

      새 장소를 만들거나 제안 후보를 실제 배출장소로 확정하지 않습니다.

    벡터 색인은 별도 실행합니다. 모델이 꺼져 있거나 연결되지 않으면 키워드 검색과 기본 안내를 사용합니다.
