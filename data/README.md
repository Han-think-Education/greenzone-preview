# 데이터 출처와 검증 상태

현재 `preview/`의 데이터는 코드에서 생성하는 **가상의 테스트 자료**입니다. 실재하는 건축물, 도로, 수거함이 아닙니다.

실데이터 연계 시 순서:

1. 서울시 행정동 경계 데이터의 이용 허가/파일 형식 확인
2. 건축물대장(표제부)에서 주용도·주소·고유식별자·좌표를 표준화
3. 행정동 Polygon 공간 조인으로 신정2동 내 건물 판별
4. 중복/좌표 누락 제거 후 10~20건만 먼저 시연
5. 양천구 공식 배출 규칙 및 실제 수거함 운영 여부 확인
6. 출처 URL, 자료 갱신일, 검증자, 검증 상태를 DB에 남김

주의: 근거리 마커라고 해서 쓰레기를 버릴 수 있는 장소는 아닙니다.
