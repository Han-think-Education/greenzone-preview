# 배출 정보 집약체와 이번 보강

2026-10-18. 그린존은 품목별 분리배출을 유지하는 공동 배출·수거·관리 구역이다.

## 분석과 웹의 역할

- **별도 분석:** 신월1동·화곡1동 4,713필지의 주거·상가·교육·의료·지역·특수 용도를 중복 분류한다. 비아파트 주거·상가는 수요 조사 대상으로, 다른 시설과 아파트 복합용도는 주변 맥락·참여 검토 대상으로 남긴다. 실제 발생량·계약·출입구는 미확인이다.
- **웹:** 분석 결과의 용도별 점·주소/건물명 검색·기준점 주변 150m 시설을 보여준다. 150m는 분석 반경이다. 안전 기준이나 운영 승인으로 표현하지 않는다.
- **도우미:** 작은 가구처럼 모호하면 품목을 되묻고 규격 버튼을 제공한다. 같은 지역에서 직전 품목의 공식 규격명을 답하면 연결한다. 지역 변경 시 맥락을 지운다.

## 데이터

- 양천구 품목 91개·규격별 수수료 268건 유지.
- 안내 요약 19개: 양천구 7개·강서구 5개·전국 공통 7개. 각각 지역·품목·질문유형·출처·확인일·기간을 기록한다.
- 학교·상가의 공공 거점 참여는 폐기물 종류·자체시설·위탁계약 확인 전이다.
- 전국 전체 품목·최신 수거함 좌표·현행 차량 정차점은 완성되지 않았다.

정본의 SQLite/JSON/CSV·출처와 추가 조사 12항목은 [상세 자료 묶음](../../GreenZone/research/derived/disposal_data_hub/README.md)에 있다. 웹에는 필요한 분석·문서 파일만 반영한다. 외부 키나 새로운 DB를 추가할 필요는 없다.

`GET /api/data-hub/status`는 파일 자료 수량만 표시한다. `GET /api/knowledge/status`는 문서·벡터 상태를 표시한다. 색인이 부족하면 키워드 검색으로 안내하며, 기존 6개 안내의 벡터는 보존하도록 동기화한다. 새 문서 임베딩은 요청 시 별도 진행한다.

`POST /api/chat`의 선택 `context`는 지역·품목 ID·확인 단계만 받으며 서버가 DB에서 다시 검증한다. 대화 원문이나 위치를 저장하지 않는다. 규격 전체 일치만 조회하며 크기·요금을 추정하지 않는다.

이번 변경은 자료 수집·가공·코드 반영이다. 자동 테스트·모델 추론·실제 운영 검증·커밋·푸시는 별도다.
