# 일반지도·위성/항공사진 전환

2026-10-18. 지도 위에서 **일반지도 / 위성·항공 / 영상+도로명**을 선택한다. 위치·배율·조사 권역·방문 번호·경로는 같은 지도 위에 유지한다.

- 일반지도: 기존 OpenStreetMap. 외부 키 불필요.
- 위성·항공: VWorld `Satellite` 타일.
- 영상+도로명: 같은 영상 위에 VWorld `Hybrid` 도로명·지명 타일을 겹친다.
- 영상 위에서는 권역 채움을 옅게 표시한다. 사진을 자세히 볼 때 ‘제안 권역’을 끌 수 있다.
- 촬영일을 확인하지 못한 사진은 **촬영일 미확인·실시간 영상 아님**으로 표시한다. 확대만으로 도로 유효 폭·높이·차량 진입을 확정하지 않는다.

## 필요한 설정

`.env`에 `VWORLD_API_KEY=발급받은_VWorld_오픈API_인증키`를 넣는다. 건축물대장 서비스키와 다르다. 기존 키에 WMTS/TMS 사용 권한과 해당 웹 주소 등록이 되어 있는지 확인한다.

선택 `VWORLD_DOMAIN`은 키에 등록한 서비스 URL을 명시할 때 사용한다. 비워 두면 현재 웹의 기본 주소를 요청의 Referer로 사용한다. 키나 등록 권한을 바꾸는 동작은 앱에서 하지 않는다.

Docker Compose는 위 두 변수를 웹 컨테이너에 전달한다. 수정 후 `docker compose up -d --build web`으로 반영한다. 로컬 실행기는 같은 이름을 읽는다. 키가 없으면 영상 버튼만 비활성화하며 일반지도는 사용할 수 있다.

## 연결 방식

- `GET /api/map/config`: 키 유무에 따른 영상 연결 가능 설정만 반환. 실제 타일 응답 성공을 뜻하지 않는다. 키값·등록 URL은 반환하지 않는다.
- `GET /api/map/tiles/{Satellite|Hybrid}/{z}/{x}/{y}`: 서버가 고정된 공식 타일 호스트에 요청하고 JPEG/PNG만 반환한다. 브라우저 주소에 인증키가 들어가지 않는다.
- 줌 1~19, 유효한 타일 인덱스만 처리한다. 공급자 오류 본문·인증 URL·예외 문자열을 사용자 응답에 노출하지 않는다.
- 서버에 타일 파일을 저장하지 않는다. API 응답은 `no-store`로 제공한다. 동시 요청은 8개로 제한한다.
- 영상 타일이 연속 실패하면 일반지도로 돌아가 권한·등록 URL·연결 상태 확인을 안내한다. 일부 누락은 별도 표시한다.

영상 연결은 배경 표시 기능이다. 수거 구역·도로 경로·안전 검토 결과를 새로 계산하거나 운영 승인 상태를 바꾸지 않는다.

## 공식 근거

- [국토교통부 WMTS/TMS API](https://www.data.go.kr/data/3046388/openapi.do): 영상·하이브리드·Leaflet 활용 및 무료 표기를 확인. 사용량은 기관 정책을 따른다.
- [VWorld 공식 활용 예제](https://github.com/V-world/Utilization-Model/blob/master/utilization-model/%5B24.06%5D%EB%A1%9C%EB%93%9C%EB%B7%B0/index.html): Satellite 타일 경로 형식을 참고했다. 예제의 공개 키를 복사하지 않고 사용자 발급 키를 사용한다.
- [VWorld 공식 QGIS 상수](https://github.com/V-world/V-QGIS/blob/main/constants.py): Satellite JPEG, Hybrid PNG 형식을 확인했다.

자동 테스트·모델 추론·영상 치수 측정·현장 안전 검증·Git 게시는 이 기능 추가에 포함하지 않는다.
