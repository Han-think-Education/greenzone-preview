키는 무엇을 받나요?
- 일반지도·기존 분석 파일로 웹 실행: 외부 API 키 0개
- 실제 건물 자료를 API로 준비: 아래 건축물대장정보 서비스 한 건부터 활용신청
- 위성·항공 / 영상+도로명: VWorld 오픈API 인증키 → VWORLD_API_KEY=, WMTS/TMS 권한. 전환 기능 구현 완료.
- 기존 키가 있다면 다시 신청하지 않고 사용합니다. SGIS·도로명주소는 지금 신청하지 않아도 됩니다.
- .env.example의 준비용 입력란을 보고, 실제 .env에 발급값을 넣습니다.
- 건축물대장 서비스키 → BUILDING_API_SERVICE_KEY=
- KOSIS 공유서비스 인증키 → KOSIS_API_KEY=
- VWorld·SGIS·도로명주소 선택 키도 예제에 사이트·발급값·입력 이름이 있습니다.
- VWorld 키는 영상지도에 사용합니다. 키 수정 후 웹을 다시 빌드합니다. 자세한 내용: MAP_IMAGERY.md
- 다른 준비용 키는 각각의 수집·조회 기능 연결 여부를 확인합니다.
