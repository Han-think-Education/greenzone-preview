# 사용자 지도와 관리자 화면

서버 실행 후 사용자 화면은 `/`, 관리자 화면은 `/admin`에서 엽니다. `/admin.html`도 같은 관리 화면입니다. 로그인·수정·이력은 기존 서버 API를 함께 사용합니다.

## 사용자 화면

1. 지도를 드래그해 이동하고 +/−, 마우스 휠 또는 두 손가락으로 확대·축소합니다.
2. **내 위치**를 누르고 브라우저의 위치 권한을 허용합니다.
3. 파란 점과 위치 오차 범위, 선택한 A/B 배치안의 가까운 제안 후보 목록을 확인합니다.
4. 후보를 누르면 지도에서 확대하고 선정 근거를 봅니다.
5. 건물을 검색해 담당 거점과 배출 규칙을 별도로 확인합니다.

현재는 모든 좌표·수요·안전 조건이 가상 자료입니다. 가까운 **제안 후보**를 보여 주며 실제 배출을 안내하는 운영 장소는 없습니다. 안전 조건이 미확인이거나 보류·제외 상태인 후보는 가까운 목록에서 제외합니다. 거리는 직선거리이며 건물별 배정이나 품목별 배출 허용을 대신하지 않습니다.

현재 위치가 분석 권역 밖이면 그 사실과 등록된 시연 후보까지의 거리만 표시합니다. 위치 권한 거부·시간 초과·위치 기능 미지원은 화면에 안내합니다. **선택 건물로 시연**은 실제 GPS 위치가 아닌 선택된 시연 건물의 좌표를 사용합니다. **위치 지우기**는 진행 중 요청의 결과도 무시하고 메모리의 기준점을 지웁니다.

위치는 버튼을 누를 때 한 번 조회합니다. 원시 위경도를 서버 API·DB·웹 저장소·주소창에 보내거나 저장하지 않습니다. 지도 타일 제공자에는 일반 지도 표시를 위한 타일 요청이 전달됩니다. 자동 추적은 하지 않습니다.

위치 기능에는 브라우저 허용과 보안 환경(HTTPS 또는 신뢰되는 localhost)이 필요합니다. 지도 배경에는 네트워크 연결이 필요하며 연결 실패 시 좌표 도식과 후보 목록을 제공합니다. 좌표 도식은 실제 배경 지도의 이동·확대를 대신하지 않습니다.

## 관리자 화면

- 담당자 로그인 후 후보 위경도·검토 상태·차량 진입·정차·작업·보행 조건·수용 기준·근거를 수정합니다.
- 배출 품목별 요일·시간·안내·원문·기준일을 수정합니다.
- SQLite 저장, 수정 충돌 확인과 변경 이력을 유지합니다.
- 사용자 화면을 다시 열면 저장된 자료로 지도와 배치 결과를 조회합니다.
- 관리 HTML의 분리는 접근 권한 자체가 아닙니다. 실제 수정 API는 기존 세션 인증으로 보호합니다. 요청 목록 API는 기존 교육용 공개 데모 범위를 유지합니다.

## 수업에서 설명할 파일

| 파일 | 역할 |
| --- | --- |
| `preview/index.html`, `app.js` | 사용자 지도·검색·가까운 후보 |
| `preview/admin.html`, `admin.js` | 로그인·후보와 규칙 수정·이력 |
| `preview/common.js` | 공통 화면 요소와 서버 통신 |
| `backend/app.py` | 동일한 자료 조회 및 인증된 수정 API |
| `backend/analysis.py` | 별도 안전 조건·거리·분산 배정 계산 |

분석은 별도 Python 작업과 결과 자료로 수행하고, 웹은 그 결과를 안내·관리합니다. 위치 계산은 AI 모델 판단이 아닌 지리 계산입니다. 선택 AI는 기존 품목·질문 의도 분류 기능을 유지합니다.

### 확인 범위

JavaScript 3개 파일과 Python 수정 파일의 문법을 확인했습니다. 로컬 `/`, `/admin`, `/admin/`, 공통·관리자 스크립트가 HTTP 200으로 제공되는 것도 확인했습니다. 실제 위치 권한, 휴대폰 터치, 지도 타일 표시, 관리자 저장의 브라우저 흐름은 별도 확인이 필요합니다. 브라우저 자동 제어 환경을 사용할 수 없어 화면 조작을 확인하지 못했습니다. 모델 호출·유료 지도·배포·테스트 모음 실행은 수행하지 않았습니다. 임시 확인 서버는 종료하며, 실행기로 다시 열 수 있습니다.
