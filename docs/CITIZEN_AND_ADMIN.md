# 사용자 지도와 관리자 화면

사용자 화면은 `/`, 관리자 화면은 `/admin`입니다. 두 화면은 같은 FastAPI 서버를 사용합니다. 실행은 [Docker 안내](../QUICK_START_KO.md)를 따릅니다.

## 사용자

1. 신월1동·화곡1동을 선택하고 도로명주소 또는 건물명으로 검색합니다.
2. 결과에서 주소를 선택하면 집과 담당 제안 조사점으로 이동합니다. 기존 분석의 필지별 배정을 조회합니다.
3. 검색어·결과 목록은 비우고 선택한 위치와 권역은 유지합니다. 검색 기록 저장은 하지 않습니다.
4. 확대·축소·일반/영상 배경 전환과 권역·도로·용도 레이어를 사용합니다.
5. 내 위치는 원하는 경우에만 브라우저 권한을 받아 조회합니다. 위치 지우기로 메모리의 위치와 진행 중 요청 결과를 해제합니다.

지도는 실제 공식 자료의 분석 결과입니다. 조사점은 운영 승인 전이며 실제 배출·정차 장소로 사용할 수 없습니다. 아파트 주거는 제안 배정에서 제외하고 학교·사업장 등은 참여·위탁계약 별도 검토 대상입니다. 직선 연결과 도로 접근 대용거리는 실제 보행 안내가 아닙니다.

주소 검색어·선택한 위치·GPS 좌표를 별도 서버나 웹 저장소에 기록하는 기능은 없습니다. 지도 공급자에는 화면 범위의 타일 요청이 전달됩니다. GPS 기능에는 HTTPS 또는 신뢰되는 localhost와 위치 권한이 필요합니다. 지도 배경은 인터넷 연결이 필요합니다.

## 관리자

설정한 사용자명·12자 이상 암호로 로그인한 뒤 후보·규칙·근거·검토 상태를 수정합니다. 수정 API는 세션 인증을 사용하며 SQLite에 저장하고 수정 충돌과 이력을 관리합니다. Docker에서는 `.env`에 암호를 직접 설정합니다.

관리자 수정은 별도 `pilot_analysis.json`의 권역·거리·도로 경로를 자동 재계산하지 않습니다. 분석 결과를 바꾸려면 별도 분석 작업과 결과 파일 반영이 필요합니다. HTML 화면을 분리한 것만으로 권한을 보호하는 구조가 아닙니다.

## 이번 공유 준비의 확인

지도·실제 영상·도로명·주소 검색·선택·담당 제안 표시와 검색창 비우기 흐름을 브라우저에서 관찰했습니다. 관리자 저장·GPS 권한 요청·휴대폰 실제 사용·모델 추론·자동 테스트·현장 검증은 이번 작업에서 수행하지 않았습니다.
