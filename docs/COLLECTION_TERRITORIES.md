# 동 전체 권역과 수거 이동 시나리오

2026-10-18 `district_corridors_v3`. 좁은 300m 블록에 조사점 6개가 몰리던 방식을 동 전체로 확장했다.

## 지도에서 보는 것

- **색 영역:** 도로망 거리로 구분한 제안 조사 권역. 권역끼리 중복 배정하지 않는다.
- **갈색 번호:** 같은 동 안에서의 방문 순서. 권역 번호와 방문 순번은 별도다.
- **점선·화살표:** 공식 도로 선형에 맞춘 권역 내부 이동 시나리오.
- **건물 용도 점:** 선택해서 켤 수 있다. 주소·건물명 검색은 유지하며 검색한 건물은 점으로 표시한다.
- **회색 영역:** 해당 격자의 도로 접근·연결 보강 필요. 안전한 곳이라는 뜻이 아니다.

두 동은 독립된 비교 시나리오다. 두 구를 하나의 수거차 노선으로 연결한 것이 아니다.

## 실제 계산 결과

|---|---:|---:|
| 동 전체 조사 대상 필지 | 1,665 | 2,706 |
| 조사 권역/점 | 6 | 6 |

| 현재 점 사이 최소 간격 | 253.8m | 306.7m |

| 도로 접근 대용거리 90백분위 | 280.8m | 383.0m |

| 같은 새 거점들의 최소 이동 순서 | 1,890.2m | 2,488.3m |

| 계산 경로에서 반복 통과한 길이 | 54.6m | 118.6m |

거리 차이는 **동일 거점·동일 도로 모델에서 방문 순서만 바꾼 비교**다. 현재 실제 수거 노선 대비 절감률이 아니다. 동 전체로 조사 범위를 넓힌 결과를 예전 300m 블록 안의 거리와 바로 비교하지 않는다.

권역당 필지 수가 균등한 것은 아니다. 현재 필지 수는 관측 단위이며 실제 쓰레기량·작업시간·수용량이 아니므로 용량을 임의 배정하지 않았다. 배출량과 청소 부담을 확보한 뒤 권역 수·범위를 다시 조정한다.

## 분석 방법

1. 기존 건축물대장·건물 도형·행정동 조인을 유지한다. 아파트 주거와 학교/의료 등 별도 참여 확인 시설의 취급은 기존 원칙을 따른다.
2. 각 동의 경계와 주변 150m 안에 있는 보관된 VWorld 도로 선형을 사용한다. 이름에 고속·지하·램프가 포함된 일부 선형을 제외한다. 도로 유형 전체를 검증한 것은 아니다.
3. 평면 교차를 노드로 나누고 양방향 연결을 가정한다. 긴 선분은 최대 약 40m 단위로 나누며 좌표는 0.1m로 양자화한다. 없는 길을 직선으로 연결하지 않는다.
4. 필지 대표점을 최근접 도로 노드와 연결한다. 80m를 넘거나 조사점과 같은 연결 성분에 속하지 않으면 미배정한다. 이번 계산에서는 두 동의 조사 대상이 모두 이 조건 안에 들어왔다. 실제 차량/보행 접근이 검증됐다는 뜻은 아니다.
5. 동 전체 수요 분포를 따라 조사점 6개를 분산한다. 점 사이 최소 250m를 적용하고 도로 접근 평균과 권역 간 이동을 함께 고려해 중앙 부근 후보를 조정한다.
6. 위치 조정의 비교 목적식은 `접근 대용거리 평균 + 0.15 × 내부 이동거리 / 점 개수`다. 90백분위·최대 접근 대용거리가 초기 분산안보다 15% 이상 늘어나는 조정은 허용하지 않는다. 수치는 프로젝트 매개변수다.
7. 확정한 6개 점의 모든 방문 순서를 상태 DP로 비교해 시작·종료가 자유인 최소 개방 경로를 계산한다. 도로 최단 경로를 사용해 선을 그린다.
8. 도로망상 가장 가까운 조사점으로 필지를 한 번씩 배정한다. 지도는 30m 격자의 도로 연결·거리로 소속을 정해 합친 면을 보여준다. 격자 근사 경계와 개별 필지 배정이 일부 다를 수 있어 배정표가 상세 기준이다.

## 해석할 범위

**현재는 양방향 평면 도로 모델의 조사 시나리오다. 실제 운행 안내·운영 배출장소·안전 승인 결과가 아니다.**

- 일방통행·회전 금지·진입 제한·고가/지하 입체교차·차량 크기·후진·정차·보행 통로·부지 권한은 추가 확인이 필요하다.
- 필지 대표점에서 도로로 연결한 직선 부분은 출입구·횡단 가능·보행 권한을 검증한 경로가 아니다. ‘도로 접근 대용거리’로 표시한다.
- 차고지·처리장·작업 시간·적재량·휴식·수거 품목별 일정은 경로에 포함되지 않았다. 내부 경로의 시작점도 실제 근무 시작점이 아니다.
- 권역 면은 제안 시각화이며 법적 배출구역·관리 경계를 지정한 것이 아니다. 도로중심선 조사점을 실제 배출면으로 사용하지 않는다.
- 250m 간격과 6개 점은 배치 비교 조건이다. 운영에 필요한 거점 수가 6개라고 입증한 것이 아니다.
