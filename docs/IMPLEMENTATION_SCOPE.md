# 그린존 학습 범위 구현안

2026-10-17 · HTML/CSS/JavaScript + FastAPI + SQLite

## 이번에 연결할 흐름

별도 CSV 분석 → 분산 후보와 배치안 A/B → 지도·건물 검색·선정 근거·배출 안내 → 담당자 정보 수정·저장.

- 공간 분석은 Python 기본 문법·CSV·거리 계산·조건 분기·정렬로 작성한다.
- 화면은 기존 HTML/JS 구조를 이어서 사용한다. 지도는 Leaflet과 일반 배경지도를 사용하고, 외부 지도 로딩 실패 시 좌표 도식과 목록을 제공한다.
- 서버는 현재 FastAPI와 SQLite를 확장한다. 기존 시연 요청 접수도 유지한다.
- 담당자 한 계정과 서버 세션으로 최소 수정 권한을 구분한다.
- AI는 정해진 품목·질문 의도만 반환한다. 사실 안내는 저장된 규칙으로 생성한다.

## 데이터의 의미

초기 건물·후보 위치·가구 수·용량·안전 조건은 모두 기능 연결을 위한 가상 자료다. 양천구 지도 배경 위에 표시하더라도 현장 조사 또는 공식 지정 장소를 뜻하지 않는다. 공공자료 URL은 조사 출처 후보이며 가상 수치의 근거가 아니다.

실제 분석 자료는 별도 CSV와 메타정보로 교체한다. 자료가 없거나 안전 조건이 미확인이면 배정에서 보류한다. 직선거리를 보행거리·차량 이동거리로 부르지 않는다. 배치 결과는 단순 탐색안이며 최적해나 실제 효과를 보장하지 않는다.

## 이번 범위에서 다루지 않는 것

CCTV·번호판·영상 감지, 실시간 단속, 실제 배출 승인·예약·결제, 전국 주소 검색, 새 모델 학습·파인튜닝.

## 실행 확인 기록

로컬 서버 시작, 첫 화면과 화면 초기화에서 호출한 catalog·config·session·requests API의 HTTP 200 응답을 서버 기록에서 확인했다. Python/JavaScript 구문을 확인했다. 브라우저 제어 도구 오류로 실제 화면 배치·클릭·관리 저장의 사용 확인은 수행하지 못했다. pytest·모델 호출·Docker 실행은 수행하지 않았다. 임시 시연 서버는 확인 후 종료하며, START_GREENZONE.bat 또는 python run_local.py로 실행한다.
