# 주소에서 담당 제안 권역 찾기

2026-10-18 추가. 위치 권한 없이 신월1동·화곡1동의 수집된 건물에서 주소·건물명을 찾고 기존 분석의 담당 제안 권역을 조회한다.

## 사용 흐름

1. 지도 위 검색창에 도로명주소 또는 건물명을 입력한다.
2. 건물명·도로명주소·지역·제안 권역이 함께 나온 결과에서 원하는 주소를 선택한다.
3. 파란 ‘집’ 표시와 담당 조사점, 강조된 제안 권역을 지도에서 확인한다.
4. 선택 요약과 오른쪽 상세에서 권역 번호·수거차 방문 순서·거리 구분을 확인한다.

결과 선택 후 검색어와 결과 목록은 비우고 선택한 위치·권역만 유지한다. 특정 주소를 고정한 검색 예시 버튼은 제거했다. 검색 기록을 저장하는 기능은 없다.

검색은 현재 지도 필터와 관계없이 두 동의 자료 전체를 대상으로 한다. 다른 동의 결과를 선택하면 해당 동으로 지도를 전환한다. 띄어쓰기와 괄호 차이를 정리하며, 여러 단어는 같은 필지의 주소·이름·용도에서 함께 찾는다. 같은 이름의 건물은 주소로 구분한다. 도로명 오타를 자동으로 고치거나 결과 하나를 임의로 확정하지 않는다.

예시로 수집 자료의 ‘밀레니엄빌라’는 **서울특별시 양천구 월정로27길 13 (신월동)**이다. ‘밀레니엄 빌라’ 또는 ‘월정로27길 13’으로 조회한다. 현재 분석에서 신월1동 3권역·방문 3번째 조사점에 연결되어 있다. 직선 35.7m와 도로 접근 대용거리 40.3m는 서로 다른 지표다. 사용자 실제 주거지로 등록한 정보가 아니다.

## 연결 근거와 범위

- `data/pilot_analysis.json`의 `buildings.features[].properties.building_id`와 `survey_assignments[].building_id`를 연결한다.
- 배정의 `reference_id`로 같은 동의 `survey_references`를 조회한다. 새 최근접 배정·외부 좌표변환·모델 추론을 수행하지 않는다.
- 아파트·시설 별도 검토·대장 미연결·도로 모델 미배정은 제안 권역 없음으로 표시한다. 임의의 가까운 점을 대신 안내하지 않는다.
- 파란 연결선은 대표점과 조사점 사이 직선이며 실제 보행 경로가 아니다. 도로 접근 대용거리는 출입구·횡단보도·계단을 확인한 보행거리가 아니다.
- 조사점과 제안 권역은 운영 승인 전이다. 실제 배출장소·시간·허용 품목은 별도 확정이 필요하다.
- 추가 API 키 불필요. 현재 건물 검색어·선택한 주소는 브라우저에서만 처리하며 저장·URL 공유·분석 서버 전송을 추가하지 않았다. 기존 영상 배경은 해당 지도 범위의 타일을 공급자에게 요청한다.
- 미수집 건물·범위 밖 주소는 지원 완료로 표시하지 않는다. 원본 갱신과 권역 재계산은 별도 분석 작업이다.

자동 테스트·모델 호출·Git 게시를 수행하지 않았다. 웹 컨테이너를 다시 빌드하고 브라우저에서 위 예시의 검색·선택·지도 표시를 관찰했다.
