그린존 프리뷰 — 무엇을 신청하고 무엇을 내려받나요?
정리일: 2026-10-19 / 간략한 5일 프로젝트
최신 실행 순서: ../README.md / 설정별 실제 사용 여부: ENV_REFERENCE.md
이 TXT의 건축HUB·KOSIS·SGIS·도로명주소는 추가 분석·원본 재수집 준비 목록입니다.
현재 프리뷰를 그대로 실행하는 팀원이 먼저 모두 가입·발급받을 필요는 없습니다.

먼저 결론
1) 일반지도와 기존 분석 파일로 웹을 실행하는 데 필요한 외부 API 키: 0개
2) 실제 건물 자료를 API로 준비한다면 먼저 신청할 서비스: 건축물대장정보 1건
3) 위성·항공 / 영상+도로명 배경: VWorld 오픈API 인증키(VWORLD_API_KEY), WMTS/TMS 권한. 전환 기능 구현 완료
4) SGIS·도로명주소 API: 지금 신청하지 않아도 됩니다.
5) 국가통계포털(KOSIS)에 가입했다면 아래 B의 KOSIS 절차를 따릅니다. SGIS와 별도입니다.

이 문서는 준비 순서의 기준입니다. 짧은 체크리스트도 같은 기준을 따릅니다.
.env.example에는 웹 실행 설정과 발급키를 미리 입력할 준비용 항목이 함께 있습니다.
발급한 키는 실제 .env에 아래 이름으로 넣습니다. VWorld 영상지도는 연결되었으며, 다른 API는 개별 연결 여부를 확인합니다.

건축HUB·KOSIS 등의 원본 재수집은 별도 분석 업무를 맡았을 때 준비합니다.
기존 .env는 덮어쓰지 않고 필요한 줄만 추가·수정합니다. 이미 건축물대장 키를 넣었다면 다시 신청할 필요 없습니다.
위 이름은 프로젝트의 설정 이름입니다. 현재 영상지도 항목만 실행용이고, 원본 수집 준비 이름은 .env.example 하단에서 주석으로 구분했습니다.
현재 분석은 정리된 파일을 읽습니다. 원본 수집·분석은 형제 GreenZone 프로젝트에서 수행합니다.
일반 주소 좌표변환은 미구현이며, VWorld 영상지도는 연결했습니다. 자세한 내용: MAP_IMAGERY.md

- 2D 지도 API는 SDK 대안 검토용이며 현재 Leaflet 유지에 필수는 아닙니다.
  국가중점은 후속 부지 속성 조회 검토용이며 세부 데이터·권한을 추가 확인합니다.

  이미지는 별도 지도 이미지 출력 명세를 확인한 뒤, 나머지는 3D·별도 앱 개발을 정할 때 검토합니다.

  영구 보관할 분석 좌표는 저장이 허용된 별도 출처로 확보합니다.
- 수거차 GPS·실제 주차 점유·쓰레기량·CCTV 영상은 이 체크만으로 제공되지 않습니다.
- 일반지도(OSM)는 키 없이 사용합니다. 위성·항공 / 영상+도로명 전환 기능은 구현했습니다.
- 선택 설정 VWORLD_DOMAIN에는 키에 등록한 서비스 URL을 적습니다. 비우면 현재 웹 주소를 사용합니다.
- .env 수정 후 docker compose up -d --build web 으로 반영합니다. 키값은 브라우저에 보내지 않습니다.
- 사용할 영상 API·허용 접속 주소·사용량·유효기간·출처 표시를 발급 화면에서 확인합니다.
- 무료 표기는 공식 카탈로그에서 확인했습니다. 2026-10-18 기존 발급 키로 Satellite/Hybrid 응답과 실제 화면 표시를 확인했습니다.
- 촬영일은 미확인이고 실시간 영상이 아닙니다. 사용량·유효기간은 본인 발급 조건을 따릅니다.
