# 프리뷰 설치·설정 안내 점검

점검일: 2026-10-19. 원격 `main`을 가져와 이전 공유 커밋 `33131d3`과 로컬 출발점이 같음을 확인한 뒤 README·예제·실행 코드를 대조했습니다. 이번 보강은 설명·설정 양식 정리이며 앱의 분석 결과·실제 `.env`·실행 DB는 수정하지 않았습니다.

## 이번에 확인한 것

- 공개 `.env.example`만 읽게 하고 셸의 같은 이름 설정도 제거한 별도 프로세스에서 Compose 설정을 해석했습니다. 실제 `.env` 내용은 출력하지 않았습니다.
- 서비스 `web` 하나, 호스트 Ollama 11434, AI 스위치 두 개 0, VWorld 키·관리 암호 빈칸, 임베딩 제한시간 60초, SQLite 이름 있는 볼륨을 확인했습니다.
- Python 파일은 구문 분석만 하고 실행하지 않았습니다. 포함된 분석·품목·문서 JSON의 파싱과 Markdown 로컬 링크 대상도 점검했습니다.
- 원본 재수집 준비용 키가 현재 프리뷰의 backend·scripts·Compose에서 사용되지 않는 점을 확인했습니다.
- `.env`·실행 DB·관리자 접속정보 제외 규칙과 커밋 대상의 실제 인증값 포함 여부를 확인합니다. 실제 키는 예제·문서에 추가하지 않습니다.

## 이번에 실행하지 못했거나 하지 않은 것

- **새 DB로 첫 실행하는 독립 컨테이너 확인은 미실행:** 현재 Docker Desktop Linux 엔진에 연결되지 않아 시작 단계에서 실패했습니다. 임시 컨테이너·DB는 생성되지 않았습니다. Compose 설정 해석은 Docker 데몬 없이 완료했으며 이를 실제 서버 시작 성공으로 표현하지 않습니다.
- 새 환경에서 모델 설치·추론·벡터 재색인·브라우저 흐름·관리자 저장·GPS 권한 요청은 수행하지 않았습니다.
- 기존 2026-10-18 화면 캡처와 실행 기록은 그대로 보관합니다. 그 기록이 모든 팀원 컴퓨터의 새 설치 검증을 대신하지는 않습니다.
- VWorld 발급 후 로그인 화면, localhost 서비스 URL의 허용 조건, 각 사람의 승인·트래픽·유효기간은 대신 확인하지 못했습니다. 공개 공식 카탈로그와 기존 연결 코드를 대조하고 신청 화면에서 확인할 항목으로 명시했습니다.

## 남은 준비를 담당별로 정리

**웹을 실행하는 팀원:** Docker Desktop·Git·인터넷 → 개인 `.env` 생성 → 기본 웹 시작. 관리자 암호·영상 키·Ollama는 원하는 기능만 추가합니다. 별도 FastAPI·MariaDB·유료 LLM 키는 기본 실행에 필요하지 않습니다.

**새 분석을 하는 팀원:** 필요한 원본·기준일·이용조건 → 별도 수집·정규화·분석 → 결과 JSON 반영. 현재 수집기는 프리뷰 저장소에 포함되어 있지 않으므로 재현 작업을 맡을 때 별도 상세 프로젝트의 스크립트·입력·매개변수 전달이 필요합니다. API 키만으로 최신 지도가 자동 생성되지는 않습니다.

**위치 실현성을 확인하는 팀원:** 현재 수거 노선·배출 규칙, 실제 출입구·보행 경로, 차량 회전·진입·정차·작업면, 부지·관리 동의, 거점 용량·배출량·청소 비용을 추가 조사합니다. 운영 승인과 안전 검증은 별개입니다.
