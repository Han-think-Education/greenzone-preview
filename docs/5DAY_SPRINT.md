## 축소 원칙

- 핵심: 건물 선택 → 품목 선택 → SQL 조회 → FastAPI 결과 → 필요할 때 Ollama 문장 생성.
- 제외: 실제 수거 예약, 계정, 결제, 관리자 인증, AI 데이터 예측, RAG, 복잡한 React 프레임워크.
- 실데이터 확보 지연: 가상임을 밝힌 프리뷰와 검증된 일부 건물만 구분하여 시연한다.
- Ollama 모델 장애: API `/api/chat`은 `mode=fallback`으로 표시하고 규칙 안내만 제공한다.
