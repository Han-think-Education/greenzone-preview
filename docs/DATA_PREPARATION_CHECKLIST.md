# 5일용 자료 준비

**신청 주소·키 이름·다운로드·현장 수집을 한 번에 보려면 [API_KEYS_AND_DATA.txt](API_KEYS_AND_DATA.txt)를 사용하세요.**

발급받은 건축물대장 서비스키는 `.env`의 `BUILDING_API_SERVICE_KEY=`, KOSIS 공유서비스 인증키는 `KOSIS_API_KEY=`에 넣습니다. [.env.example](../.env.example)에 신청 사이트와 준비용 입력란이 있습니다. VWorld·SGIS·도로명주소는 기능을 추가할 때 선택합니다. 외부 자료 자동 수집은 아직 미구현이며 현재 웹 실행에는 키가 필수가 아닙니다.

작은 권역의 후보 비교와 안내 웹에 필요한 항목만 준비합니다. 상세 조사·장기 확장 목록은 별도 GreenZone 프로젝트에서 관리합니다.

| 준비할 것 | 할 일 | 공식 주소 |
| --- | --- | --- |
| 대상 블록 | 분석할 도로·건물 범위 하나 정하기 | 팀에서 결정 |
| 현행 배출 규칙 | 대상 동·품목·요일·시간·예외·원문·기준일 정리 | [양천구 공지](https://data.yangcheon.go.kr/openinf/sheetview.jsp?infId=OA-12718&tMenu=11) |
| 현재 배출·수거 위치 | 배출점과 차량 정차점을 구분하고 확인 근거 기록 | [양천구청](https://www.yangcheon.go.kr/)·업체 자료·허용된 현장 확인 |
| 건물·수요 | 주소·좌표·주거형태·가구 또는 건물 수와 단위 | [건축물대장 API](https://www.data.go.kr/data/15134735/openapi.do), [인구·세대 파일](https://jumin.mois.go.kr/statMonth.do) |
| 후보 안전 조건 | 차량 진입·정차·작업면·보행 통로·관리 책임 확인 | 기관·업체 자료·현장 근거 |
| 분석 전달 파일 | 후보·건물 CSV, 규칙·출처·권역 메타정보 | data/README.md 참고 |

## 필요한 신청

- **KOSIS 국가통계포털에 가입했다면** [통합 TXT의 KOSIS 절차](API_KEYS_AND_DATA.txt)를 따릅니다. 우선 대상 동 인구 통계 파일을 받고, 자동 수집을 준비할 때만 [공유서비스](https://kosis.kr/openapi/index/index.jsp)에서 활용신청·인증키 발급을 진행합니다. KOSIS와 SGIS는 별도 서비스이며 현재 둘 다 웹 자동 수집은 없습니다.
- 현재 Leaflet+OSM 지도·내 위치·직선거리 계산에는 별도 지도 키가 필요하지 않습니다.
- 건축물대장 API를 사용할 때만 활용신청·서비스키·가이드를 준비합니다. 실제 응답·필드를 확인합니다.
- 가구 자료가 없으면 건물 수 등 같은 단위로 비교하고 가정을 밝힙니다. 미확인 안전 조건은 보류합니다.
- 원본·출처·자료 기준일·단위·좌표계·누락을 함께 기록합니다. 키 값은 공개 문서에 적지 않습니다.

## 이번 범위

기존 품목과 지도·분석·안내·정보 수정 연결에 집중합니다. 음식물·영상지도·일반 주소 API·QR·RFID·실시간 운행·단속·치안 연계는 후속 선택입니다. 2020 음식물 수거표는 과거 구역 자료이며 현재 GPS·정차점·일반폐기물 기준선으로 간주하지 않습니다.
